4.1 v1.0 集成阶段修复的 7 个真实缺陷

  • FIX-1 相对路径双重解析 — renderer 页面基底导致 renderer/renderer/app.js 404，模块从未执行 → 根相对路径 + importmap 修复
  • FIX-2 Chromium 磁盘缓存旧模块 — no-cache 无验证器失效 → no-store
  • FIX-3 IPC 死循环 — setHeartMode↔run('return') 互相触发，return 动画无限重播 → 单向 app:awaken 通知
  • FIX-4 骨骼旋转永不生效 — 主循环漏调 vrm.update()，normalized 骨骼旋转无法同步到蒙皮骨骼（手臂恒 T-pose）→ 补同步调用
  • FIX-5 HuggingFace 被墙 — WinError 10060 模型下载失败 → HF_ENDPOINT=hf-mirror.com
  • FIX-6 PyAV API 不兼容 — av 19 移除 metadata_errors 参数 → 锁定 av==15.1.0（签名实测）
  • FIX-7 CUDA DLL 跨线程丢失 — cublas64_12.dll 识别期找不到 → PATH + add_dll_directory + ctypes WinDLL 三重保障

4.2 v1.0.1 UI 打磨阶段修复的 5 项体验问题

  • FIX-8 人物位置与功能栏不对齐 — 硬编码 basePos (2.2, -0.15) 与工具栏位置无关 → 动态计算（对齐工具栏中心 + Box3 实测模型脚底补偿，任意分辨率/DPI/模型自适应），像素验证偏差 ~1px
  • FIX-9 打招呼手势不像参考图 — 手臂举幅不足/掌心朝向偏 → 按用户示意图重定义（举至头侧同高、掌心朝观众、轻摆），基于 VRM 骨骼规范的几何脚本精确推算参数，两轮收敛
  • FIX-10 工具栏 hover 死区 — 鼠标从人物移向工具栏途中脱离“接近”判定，工具栏消失且窗口穿透点不到按钮 → _uiHover 区域判定（工具栏± 20px，隐藏态兼作唤出）+ 淡出防抖 260ms + 聊天/设置/换装面板同步保护
  • FIX-11 启动时半成品人物闪现 — BrowserWindow 默认创建即显示 + setModel 瞬时全显，纹理未上 GPU 的白/半透明帧直接亮出 → show:false + 模型就绪后 window:show IPC 揭示 + 15s 超时兑底 + 移除瞬时 setOpacity(1)
  • FIX-12 唤醒/休息后纹理虚影 — 窗口隐藏期间 Chromium 回收 GPU 纹理，唤醒后 ~640ms 无纹理虚影，且 opacity 无法遮盖 MToon outline/shade pass → canvas 元素级 visibility:hidden 700ms（合成跳过但 WebGL 绘制照常重传纹理）+ disable-renderer-backgrounding 等三开关从根源阻止隐藏窗口资源降级

4.3 v1.0.3 流式与健壮性阶段修复的 4 项
