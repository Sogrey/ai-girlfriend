## 1. 产品概述

### 1.1 一句话定位

一个**长期驻留在 Windows 桌面上的实时 3D AI 虚拟伴侣**：透明无边框窗口中的 VRM 角色，能看着你的鼠标、听你说话、开口回应并同步口型、做动作、表达情绪、换装、离开休息与召回——像一个真正"住"在电脑里的人。

### 1.2 设计愿景

> 打开程序后，用户桌面上多了一个会说话、会看着自己、会做动作、会回应自己的 3D AI 角色。她不是网页弹窗，不是聊天工具，而是桌面本身的一部分。

### 1.3 目标用户

- 长时间使用 Windows 工作站办公的独居青年/技术从业者
- 需要 AI 陪伴但抗拒传统"聊天框"形态的用户
- 桌面美化爱好者（Wallpaper Engine、桌面宠物用户群）

### 1.4 核心价值

| 价值点 | 说明 |
|---|---|
| **真实存在感** | 透明窗口 + 全屏眼神追踪 + 物理Idle（呼吸/眨眼/发丝物理），角色有"活着"的感觉 |
| **多模态自然交互** | 语音（说）→ STT → LLM → TTS（听）→ 口型同步（看），全链路延迟在秒级 |
| **主动行为能力** | LLM 输出结构化 JSON（emotion + action），角色能执行换装/离开/返回等真实动作，而非只输出文字 |
| **可成长人格** | System Prompt 独立文件 + 角色名/用户称呼/性格可配置 + 上下文记忆 |
| **服务可插拔** | LLM 双 Provider（DeepSeek 在线 / Ollama 本地）、TTS Provider 架构化，业务逻辑与具体服务解耦 |

### 3.3 动画系统（程序化状态机）

### 5.2 通信协议（WS，JSON + base64）

| 方向 | 消息 | 载荷 |
|---|---|---|
| R→B | `user_message` | `{text}` 文字对话 |
| R→B | `transcribe_audio` | `{data: base64 webm/opus}` 语音识别 |
| R→B | `speak_line` | `{text, emotion}` 本地台词直读（摸头反应） |
| R→B | `reload_config` / `ping` / `get_status` / `clear_history` / `get_history` | 控制（get_history：拉取持久化历史供重启回填） |
| B→R | `stt_result` | `{text}` 识别结果 |
| B→R | `ai_response` | `{reply, emotion, action, costume}` 结构化意图 |
| B→R | `llm_partial` | 流式增量帧（SSE delta，打字机效果） |
| B→R | `tts_audio` | `{seq, final, data: base64 mp3}` 逐句音频 |
| B→R | `history_replay` | `{items}` 重启后历史回填 |
| B→R | `tts_audio` | `{seq, final, data: base64 mp3}` 逐句音频 |
| B→R | `status` / `error` | 状态与错误 |

### 5.3 Action 协议（LLM → 渲染）

```json
{"reply": "...", "emotion": "happy|shy|angry|sad|surprised|caring|neutral",
 "action": "idle|wave|leave|return|change_costume|comfort|head_pat|jump|dance|think",
 "costume": "casual|school|stylish|gothic|seed|null"}
```

校验层（`backend/actions/definitions.py`）：非法值归一、动作别名映射（如 `pat→head_pat`）、change_costume 缺失时从回复文本猜服装关键词。

### 5.4 配置系统

- `config/config.json` — 默认配置（版本管理）
- `config/user.json` — 用户覆盖（设置面板写入，git 忽略，API Key 与 window.x/y 存此处）
- `config/history.jsonl` — 对话历史追加落盘（git 忽略，重启恢复上下文/回填）
- 深度合并语义，两侧进程（Electron main / Python backend）独立实现一致的 merge；读侧 BOM 容错（readJsonSafe）
